constexprnoexcept

The configuration menuconfig selected, on top of the defaults.

A Kconfig bool is defined when it is y and absent when it is n, so the booleans follow Kconfig only when this component's Kconfig is active (CONFIG_CANOPEN_CLIENT is defined); otherwise they keep the Config{} defaults.
