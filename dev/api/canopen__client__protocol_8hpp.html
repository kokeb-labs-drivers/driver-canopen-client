Detailed Description

The CANopen frame codecs: pure functions that build and decode NMT, SYNC, SDO, heartbeat, EMCY and PDO frames and the drive statusword. No I/O, no state.

Every builder validates its arguments and returns Error::InvalidArgument for a bad one, so no frame with a wrong identifier or length is ever built. Every decoder validates the frame it reads (identifier, length, command specifier) and returns Error::InvalidFrame for a frame that does not fit; it never reads past dlc. The fuzz target drives them with arbitrary frames.
