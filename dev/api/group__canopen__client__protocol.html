constexpr Result< SdoReply > canopen_client::ParseSdoReply ( const CanFrame &  frame,
bool  strict 
)
constexprnoexcept

Decode a frame from an SDO server (identifier 0x580 + node).

The identifier is the caller's to check; this reads the payload. Block-transfer command specifiers (5 and 6) and the reserved 7 are not replies to a request this client sends and are InvalidFrame.

Parameters
frameThe frame.
stricttrue to require 8 data bytes in every SDO frame; false to accept a frame as short as its content needs (4 bytes for an initiate reply, 1 for a segment reply).
Returns
The reply, or InvalidFrame (remote frame, too short, or an unusable command specifier).
