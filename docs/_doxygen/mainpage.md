# CANopen client driver API reference {#mainpage}

The classes, types and codecs of the CANopen client driver, generated from the headers in `inc/`.

Start with canopen_client::Client, the driver, and canopen_client::CanInterface, the base of the port you write.
Errors are canopen_client::Error inside canopen_client::Result; the configuration is canopen_client::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">CANopen client driver
documentation</a>.
